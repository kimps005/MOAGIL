# 모아길 (MOAGIL)

여러 동승자가 각자의 하차 지점을 등록하면, 운전자가 가능한 하차 순서를 확인하고 단계별 안내를 이어가는 시연용 공동 이동 프로토타입입니다.

> 이 저장소는 **브라우저 기반 차량 화면 + 스마트폰 참가 화면 + Python/SQLite 서버**로 P0 사용자 흐름을 재현합니다. Android 네이티브 APK, 실제 지도·도로 탐색, 실시간 교통, 실제 차량 위치, Pleos 내비게이션은 포함되거나 검증되지 않았습니다. 모의 순서 추천은 좌표 사이 직선거리로 추정하며 실차 운행에 사용하지 마세요.

## 빠른 실행

요구 환경: Python 3.12 이상, 현대 브라우저. 서버와 웹은 외부 패키지 없이 실행됩니다.

```powershell
.\Start-MOAGIL.ps1
```

또는 저장소 루트에서:

```powershell
python backend/server.py
```

차량 화면은 `http://localhost:8080`에서 열립니다. 스마트폰 참여를 시연하려면 차량과 스마트폰을 같은 Wi-Fi에 연결한 뒤 차량 화면의 QR을 스캔하세요. 격리된 LAN에서만 HTTP를 사용하고, 방화벽이 차단하면 로컬 운영자가 네트워크 접근을 허용해야 합니다. 초대 링크는 참가 권한을 가지며 이동을 종료하면 사용할 수 없습니다.

## 시연 순서

1. **시연 데이터로 시작**을 누르면 예시 출발지와 네 명의 테스트 승객이 들어갑니다. 실제 위치 데이터는 아닙니다.
2. **정차 상태 확인**을 눌러 `정차(시연)`으로 바꿉니다. 이 토글은 차량 센서가 아닙니다.
3. **가능한 순서 계산**을 누릅니다. 우선 승객이 없으면 4명 기준 24개, 한 명을 먼저 내리도록 지정하면 6개 순서를 비교합니다.
4. 위/아래 버튼으로 순서를 조정한 뒤 **경로 확정 · 모의 안내**를 누릅니다.
5. 각 단계에서 운전자가 **하차 완료 · 시연**을 누르고 마지막에 이동을 마칩니다.

실제 참가 흐름은 **빈 이동 만들기**로 새 세션을 만든 뒤, 차량과 같은 네트워크의 별도 스마트폰에서 QR을 스캔해 별명과 핀을 등록하면 됩니다. 참가 웹은 이름과 지정 좌표를 차량 화면에 표시합니다.

## 기능과 검증 범위

| 영역 | 현재 구현 |
|---|---|
| 차량 화면 | 브라우저에서 동승자, 경로 순서, 상태, mock 내비 단계를 표시 |
| 동승자 웹 | QR 참여, 별명, SVG 시연 지도 핀 터치/드래그, 좌표 입력, idempotent 등록 |
| 서버 | 세션·토큰 해시·4명 제한·SQLite 상태 저장·2초 폴링·version 충돌 처리 |
| 경로 순서 | 1~4명 모든 순열, 우선 승객 고정, 동률 정렬, Haversine 기반 시연 추정 |
| 안전 표시 | 정차(시연) 확인 전 운전자 변경·계산·안내·하차 동작 차단 |
| P1 실제 연동 | 미구현. 네이버 Directions 5와 Pleos 계정/인증/SDK를 검증하지 않음 |
| Android APK | 미제공. 이 개발 환경에 Android SDK/API 34 및 JDK 17/Gradle 빌드 구성이 없어 빌드하지 못함 |

### 모의 기능 안내

- SVG 배경 지도와 좌표는 시연용이며 실제 지형, 도로, 합법적 정차 지점을 나타내지 않습니다.
- 순서 비용은 Haversine 직선거리의 1.25배 및 고정 시속 가정으로 산출합니다. 실제 교통이나 주행시간이 아닙니다.
- 차량 정차 상태, 차량 위치, 내비 요청 및 성공/하차 진행은 모의 상태입니다.
- 외부 지도 서비스, API 키, 분석 SDK, 계정은 사용하지 않습니다.

## 개발 및 확인

```powershell
# 순열 엔진 단위 테스트
python -m unittest discover -s backend/tests -v

# 브라우저 E2E 및 시연 영상 재생성에 필요한 Playwright 도구
pnpm install

# 서버 실행 (별도 PowerShell 창)
python backend/server.py

# 별도 터미널에서 브라우저 흐름 확인
pnpm test:e2e

# 2분 30초 안팎의 무음 시연 영상 생성
pnpm record:demo
```

시연 영상에는 한국어 화면 자막이 들어가며 음성 내레이션은 없습니다. 촬영 보호 모드는 초대 QR을 가리고, 영상 속 모바일 화면은 실제 스마트폰이 아니라 별도 참가 웹을 같은 브라우저 안에서 연 것입니다.

## 저장 및 데이터

- 세션과 참가 정보는 `backend/data/moagil.db`에 저장됩니다. 이 폴더는 Git에서 제외됩니다.
- 세션 TTL은 2시간이며 세션 종료 후 참가 링크가 닫힙니다. 서버 재시작 뒤에도 SQLite 세션은 남습니다.
- `MOAGIL_DB` 환경 변수를 지정하면 데이터베이스 위치를 바꿀 수 있습니다.
- 초대 및 운전자 토큰은 서버 DB에 SHA-256 해시로만 저장하고 HTTP access log에는 URL을 기록하지 않습니다.
