# 시연 영상 가이드

## 영상 파일

`demo/video/MOAGIL-demo.webm`은 브라우저 기반 시연 프로토타입에서 생성한 무음 WebM 영상입니다. `demo/run-demo.cjs`는 가상 참가 브라우저 등록부터 차량 화면의 동기화, 정차 게이트, 우선 승객, 순서 조정, 단계별 mock 내비 안내까지 재현합니다. 길이는 약 2분 40초이며, 최신 버전은 다음 명령으로 다시 만듭니다.

```powershell
pnpm record:demo
```

촬영 시 `?capture=1` 보호 모드를 사용합니다. 실제 초대 QR과 초대 토큰은 화면에 출력하지 않습니다. 프레임 속 참가 화면은 같은 브라우저에서 열린 가상 참가 페이지입니다. 실제 별도 휴대폰 연결 장면을 찍은 것이 아닙니다.

## 스토리보드

| 구간 | 장면 | 화면 자막 |
|---|---|---|
| 0:00–0:10 | 목적지가 여러 개인 귀가 상황 | 여러 목적지, 순서는 한 번에. |
| 0:10–0:20 | 새 이동과 QR 초대 | 이동 세션과 초대 링크를 만들어요. |
| 0:20–0:40 | 가상 모바일 참가 페이지와 핀 지정 | 별명과 핀을 등록합니다. |
| 0:40–0:55 | 등록 결과와 정차 게이트 | 정차 확인 전 운전자 입력은 잠겨 있습니다. |
| 0:55–1:10 | 네 명 예시 데이터 및 위치 지도 | 예시 좌표와 시연 지도입니다. |
| 1:10–1:30 | B 우선 지정, 6개 비교 | 우선 하차 조건이 계산에 반영됩니다. |
| 1:30–1:45 | 수동 순서 재조정 | 운전자가 순서를 직접 조정할 수 있습니다. |
| 1:45–2:00 | 계산 결과와 확정 화면 | 총 예상 시간과 비교 개수를 확인합니다. |
| 2:00–2:25 | 네 단계의 하차 완료 | 하차마다 다음 안내를 확인합니다. |
| 2:25–2:40 | 운전자 목적지와 한계 안내 | 실제 도로·교통·내비는 별도 검증이 필요합니다. |

측정되지 않은 시간 절감, 안전 향상, 실제 교통 정확도를 주장하지 않습니다. 음성, 음악, 외부 지도 타일은 포함하지 않습니다.
